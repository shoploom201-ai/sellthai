# 🏺 ATELIER NOOK (아틀리에 눅)
> **"일상을 채우는 조용하고 단단한 오브제"**  
> 기본에 충실하면서도 감각적인 라이프스타일 & 리빙 셀렉트숍 웹사이트

---

## ✨ 사이트 특징 및 센스 있는 디테일

1. **미니멀 & 웜 뉴트럴 비주얼 아이덴티티**:
   - 따뜻한 오프화이트/크림톤(`--bg-primary: #FAF8F5`)과 차콜/스톤 블랙 컬러 팔레트
   - 우아한 영문 세리프 폰트(`Cormorant Garamond`)와 가독성 높은 한글 산세리프(`Pretendard`)의 조화
   - 정갈한 여백과 그리드 시스템

2. **쇼핑 인터랙션 & UX 디테일**:
   - **스무스 이미지 호버**: 제품 카드에 마우스를 올리면 다른 각도의 라이프스타일 컷으로 부드럽게 전환
   - **사이드 슬라이드 장바구니 (Cart Drawer)**: 페이지 이동 없이 우측에서 열리는 장바구니
   - **5만 원 이상 무료배송 계산기 게이지**: 실시간 남은 금액 및 달성률 시각화
   - **상세 퀵 뷰 모달 (Quick View)**: 옵션 선택, 수량 조절, 상세 스펙 확인
   - **위시리스트 (찜하기)**: 로컬스토리지 연동으로 브라우저를 껐다 켜도 저장 유지
   - **가상 주문 및 결제 시뮬레이션**: 배송지 입력 폼 및 결제 완료 모달
   - **감각적인 토스트 알림**: 카트 추가 및 찜하기 시 반응형 알림 피드백
   - **실시간 카테고리 필터 & 검색 & 정렬**: (인기순 / 신상품순 / 가격순)

## 🚀 사이트 바로 열어보기

별도의 빌드 도구나 설치 과정 없이 즉시 실행할 수 있습니다.

1. **탐색기에서 바로 실행**:
   - `website` 폴더 안의 `index.html` 파일을 더블클릭하여 크롬 등 브라우저로 엽니다.

2. **로컬 서버로 실행 (권장)**:
   - 터미널(PowerShell 등)에서 아래 명령어 실행:
   ```bash
   python -m http.server 8000
   ```
   - 브라우저 주소창에 `http://localhost:8000` 입력

## 🔐 관리자 모드 (사진·상품 정보 업로드)

`/admin.html` 에서 비밀번호로 로그인한 뒤 상품 사진을 올리고 이름·가격·설명·옵션 등 기본 정보를 수정할 수 있습니다.
저장하면 메인 사이트에 바로 반영됩니다. (관리자 기능은 **Cloudflare Pages** 배포 환경에서 동작합니다.)

- 사진은 클릭 또는 드래그로 여러 장 업로드 (브라우저에서 자동으로 줄여서 업로드, 상품당 최대 10장)
- 상품명·판매가가 입력되어 있으면 사진을 올리는 즉시 자동 저장되어 사이트에 바로 반영 (사진 삭제·대표 변경도 동일)
- 첫 번째 사진 = 대표 사진, 두 번째 사진 = 마우스를 올렸을 때 보이는 사진
- 상품 추가 / 수정 / 삭제 / 순서 변경(▲▼)
- 로그인 10회 실패 시 15분 잠금, 로그인 유지 12시간
- **디자인 스타일 변경**(테마 색상·모서리·진열 열 수·브랜드명·메인 문구)은 관리자로 로그인했을 때만 사이트에 버튼이 보이며, 바꾼 내용은 모든 방문자에게 적용됩니다. 관리자 화면 상단의 [디자인 스타일 변경]으로 바로 열 수 있습니다.

### 최초 1회 설정 (Cloudflare 대시보드)

1. **Workers & Pages → KV → 네임스페이스 만들기** (이름 예: `sellthai-data`)
2. Pages 프로젝트 → **설정 → 바인딩 → KV 네임스페이스 추가**
   - 변수 이름: `SELLTHAI_KV` / 네임스페이스: 위에서 만든 것
3. Pages 프로젝트 → **설정 → 변수 및 비밀 → 추가**
   - `ADMIN_PASSWORD` : 관리자 비밀번호 (유형: **암호화/Secret**, 길고 추측하기 어렵게)
   - `SESSION_SECRET` : (선택) 아무 긴 임의 문자열
4. 다시 배포 → `https://내도메인/admin.html` 접속

### 로컬에서 관리자 모드 테스트

```bash
npx wrangler pages dev . --kv SELLTHAI_KV --binding ADMIN_PASSWORD=test1234
```

> 아직 한 번도 저장하지 않았다면 사이트는 `js/data.js` 의 기본 상품을 보여주고,
> 관리자 화면도 그 목록을 시작점으로 불러옵니다. 첫 저장 이후에는 저장된 목록이 사용됩니다.
